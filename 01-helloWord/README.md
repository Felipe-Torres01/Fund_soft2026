# 01-helloWord

Projeto Spring Boot criado automaticamente.

## Requisitos

- Java 25
- Maven

## Executar

```bash
mvn spring-boot:run
```

Acesse:

http://localhost:8080

## Testes

```bash
mvn test
```

## Empacotar

```bash
mvn clean package
```

## Executar o JAR

```bash
java -jar target/01-helloWord-1.0-SNAPSHOT.jar
```
